# Lospia — 7 Günlük Onboarding Checklist

> Her yeni müşteri için kopyalanır. Günler iş günüdür; müşterinin veri/form
> teslim hızına göre 7-14 iş gününe uzayabilir (sözleşme dili buna göre).

**Müşteri:** ______________________
**Başlangıç tarihi:** ______________________

## Gün 0 — Ödeme + form

- [ ] Hizmet sözleşmesi + Scope of Work imzalandı
- [ ] Kurulum ücreti tahsil edildi (ödeme gelmeden kurulum başlamaz)
- [ ] Müşteri bilgi formu gönderildi (ekip listesi, departmanlar, mevcut Excel)
- [ ] Dahili takip kartı açıldı

## Gün 1 — Keşif

- [ ] 60 dk keşif görüşmesi yapıldı
- [ ] Mevcut Excel / WhatsApp / Notion akışı incelendi
- [ ] En kritik 3 operasyonel ağrı yazıldı
- [ ] Onay akışları ve karar vericiler netleştirildi

## Gün 2 — Süreç haritalama

- [ ] Departman / kategori yapısı taslağı çıkarıldı
- [ ] Statü akışı tanımlandı (Yapılacak → Devam → Onay bekliyor → Tamamlandı)
- [ ] Rol dağılımı belirlendi (owner / admin / member / viewer)
- [ ] Müşteri onayı alındı (yazılı)

## Gün 3 — Workspace kurulumu

- [ ] Workspace oluşturuldu (müşteri marka adıyla)
- [ ] Departmanlar / kategoriler kuruldu
- [ ] Haftalık görünüm ve panolar yapılandırıldı

## Gün 4 — Modüller ve statüler

- [ ] Standart modüller açıldı / kapatıldı (kapsamına göre)
- [ ] Statüler ve kurallar alanı dolduruldu
- [ ] Örnek görevlerle akış test edildi

## Gün 5 — Veri aktarımı + davetler

- [ ] Excel/CSV import yapıldı (SOW'daki satır limiti dahilinde)
- [ ] Aktarılan veriler müşteriyle doğrulandı
- [ ] Kullanıcı davetleri gönderildi, roller atandı

## Gün 6 — Eğitim

- [ ] 45-60 dk canlı ekip eğitimi yapıldı
- [ ] Her kullanıcı en az 1 görev oluşturdu/güncelledi
- [ ] Yönetici haftalık görünümü kullanmayı gördü
- [ ] Eğitim kaydı / kısa kılavuz paylaşıldı

## Gün 7 — Teslim + destek başlangıcı

- [ ] Teslim görüşmesi: kurulum kapsamı SOW ile karşılaştırılarak kapatıldı
- [ ] 14 günlük destek periyodu resmen başladı (bitiş tarihi: __________)
- [ ] 14. gün kontrol görüşmesi takvime eklendi
- [ ] 30. gün başarı ölçümü + case study talebi hatırlatıcısı kuruldu

## Destek dönemi (Gün 7-21)

- [ ] 14. gün kontrolü: kullanım var mı? Ekip davetleri aktif mi? Tıkanma nerede?
- [ ] 30. gün: başarı ölçümü, case study / referans izni istendi
