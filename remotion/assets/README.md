# Lospia demo video — Remotion

This folder holds the **isolated** Remotion project that renders the 60-second
Lospia product demo. It is deliberately decoupled from the Next.js app:

- `remotion/` is **excluded** from `tsconfig.json`, so `npm run typecheck`
  never depends on Remotion being installed.
- No app code (`app/`, `components/`, `lib/`) imports from `remotion/`.
- Remotion is **not** in `package.json` — it is an optional, on-demand tool.

## Screenshot-first — this is the important part

The product scenes are **real screenshots of the local Lospia app**, not
Remotion-drawn fake UI. Redrawing the UI made the video look like a generic AI
SaaS mockup (pastel toy cards, low density, empty space). Instead we capture the
actual app and turn it into a guided "Loom-style" tour: subtle camera zoom,
gliding cursor, one soft highlight per scene, a small callout. Only the intro /
problem / CTA are Remotion-drawn brand title cards.

Pipeline:

1. Seed / verify the demo-safe workspace (`scripts/seed-demo-workspace.ts`) —
   local only, `@demo.lospia.test` users, **no** real customer / Aslı Filinta
   data, **no** "Lookbook" / fashion-only wording.
2. Capture: `node scripts/capture-lospia-screenshots.mjs` (Playwright logs into
   the local dev server as `elif@demo.lospia.test`) → writes
   `remotion/assets/screenshots/*-reference.png` (3200×2000) + `manifest.json`.
3. Copy the captured PNGs into `public/demo/screenshots/` so Remotion can load
   them via `staticFile("demo/screenshots/<name>.png")`.
4. Render (below).

If a route can't be captured, capture what exists and only fall back to a
product-faithful card for the missing view.

## Video spec

- 1920×1080 · 60s · 30fps (1800 frames)
- Light Lospia brand: off-white canvas, deep graphite text, cobalt accent used
  sparingly (cursor / highlight), soft borders, subtle shadows, Lospia wordmark
- Real product screenshots framed in a near-full-bleed app window (~90% width /
  ~80% height) so the app shell (sidebar + header) stays visible and dense
- Structure: `LospiaDemo.tsx` (composition), `data/lospiaDemoData.ts` (copy +
  scene timeline + captions), `styles/lospiaVideoTheme.ts` (light theme tokens)

## Scenes

| Time    | Frames     | Scene                                   | Source                    |
| ------- | ---------- | --------------------------------------- | ------------------------- |
| 0–3s    | 0–90       | Logo intro                              | drawn                     |
| 3–7s    | 90–210     | Problem context (compact cards)         | drawn                     |
| 7–24s   | 210–720    | Board walkthrough (Kontrol / Onay)      | `board-reference`         |
| 24–36s  | 720–1080   | Task detail / approval                  | `task-detail-reference`   |
| 36–47s  | 1080–1410  | List + calendar visibility              | `list` + `calendar`       |
| 47–54s  | 1410–1620  | Weekly summary                          | `dashboard-reference`     |
| 54–60s  | 1620–1800  | Final CTA                               | drawn                     |

Captions are shown only on the product scenes (the drawn scenes carry their own
headline), bottom-center and raised (~118px) so they never clash with the video
player controls.

## Voice-over

Optional, single continuous **female** Turkish master at
`public/demo/audio/lospia-voiceover-master.wav` (generated by
`lospia-tts-lab/scripts/generate_lospia_female_voiceover.py`). Never per-scene
files. The render script auto-detects it; if missing, the video renders silently
with captions. Bad AI voice is worse than none.

## One-time install (not committed to package.json)

```bash
npm install --no-save remotion @remotion/cli @remotion/bundler @remotion/renderer
```

> `--no-save` keeps the app's dependency graph clean. If you decide to make the
> demo a permanent part of the build pipeline, install without `--no-save` and
> commit the lockfile change deliberately.

## Preview in the Remotion Studio

```bash
npx remotion studio remotion/index.ts
```

## Render to the public folder

```bash
bash scripts/render-lospia-demo.sh
# → writes public/demo/lospia-demo.mp4
```

Once `public/demo/lospia-demo.mp4` exists, the landing page's `<DemoVideo />`
slot detects it at render time and swaps the placeholder for the real HTML5
player automatically — **no code change required**.

### Optional poster

Export a still (e.g. from the board scene) to
`public/demo/lospia-demo-poster.png` and it is used as the video poster and the
placeholder background automatically:

```bash
npx remotion still remotion/index.ts LospiaDemo public/demo/lospia-demo-poster.png --frame=600
```

## Brand assets

The composition pulls the Lospia icon from `public/brand/lospia/icon_white.png`
via Remotion's `staticFile()`. Put any additional demo-only stills in this
folder (`remotion/assets/`).
